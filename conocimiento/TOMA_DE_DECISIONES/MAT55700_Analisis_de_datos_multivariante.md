## 📝 Descripción

Asignatura cuantitativa enfocada en el análisis simultáneo de múltiples variables para identificar patrones, relaciones y estructuras en conjuntos de datos complejos. Integra técnicas como análisis de componentes principales, factorial, de conglomerados y discriminante, entre otros.

---

## 🎯 Aprendizajes clave

- Identificar patrones y relaciones en datos multidimensionales.
- Aplicar técnicas multivariantes para el Análisis de datos complejos.
- Interpretar resultados en contextos organizacionales.
- Tomar decisiones basadas en análisis avanzados de datos.

---

## 💼 Valor profesional

Permite desarrollar capacidades avanzadas de análisis de datos para la toma de decisiones estratégicas, con alta aplicabilidad en investigación de mercados, análisis financiero y gestión organizacional. Además de: marketing, negocios, medicina, finanzas, economía.
