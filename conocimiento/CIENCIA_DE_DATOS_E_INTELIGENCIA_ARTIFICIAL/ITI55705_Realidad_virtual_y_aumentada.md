## 📝 Descripción

Esta materia te enseña a crear experiencias digitales usando realidad virtual y aumentada. Aprendes a desarrollar soluciones creativas para representar y manejar datos con herramientas tecnológicas emergentes. Trabajas con programación y entornos digitales para resolver problemas de forma innovadora. Se recomienda contar con bases en análisis de datos y programación.

---

## 🎯 Aprendizajes clave

- Distinguir entre realidad virtual, aumentada y sus usos.
- Analizar tecnologías actuales para crear soluciones digitales interactivas.
- Diseñar soluciones innovadoras con VR/AR para problemas reales.
- Utilizar plataformas para desarrollar aplicaciones VR/AR.
